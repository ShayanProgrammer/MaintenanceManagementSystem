# MaintenanceManagementSystem.Client

Angular 21 standalone client for the Maintenance Management System.

Setup, configuration, run, test, and build instructions live in the
repository root [README.md](../README.md). Project conventions for this
directory are in [CLAUDE.md](../CLAUDE.md).

Quick reference (run from this directory; see the root README for prerequisites):

```bash
npm install
npm start        # dev server at http://localhost:4200
npm test         # unit tests (Vitest)
npm run build    # production build → dist/
```
